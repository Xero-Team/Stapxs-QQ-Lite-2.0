# ADR 0001: Independent privacy-first fork

- Status: accepted
- Date: 2026-09-12

Xero QQ Lite is an independent Xero-Team fork. Upstream branding, update feeds,
remote announcements, sponsor/contributor widgets and telemetry are removed.
OneBot 11 compatibility and third-party license notices remain required.
External integrations are opt-in and local data stays on the device by default.
