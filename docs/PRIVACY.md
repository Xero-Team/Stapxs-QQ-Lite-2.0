# Privacy policy

Xero QQ Lite is offline-first. It does not include analytics, telemetry, crash reporting, fingerprinting, or beacon requests. No message content, account identifiers, tokens, complete URLs, or local file paths are sent to Xero-Team.

Network connections occur only to a OneBot endpoint or an explicitly enabled integration (for example media preview). Users can disable integrations and clear local history/cache from Settings. OneBot servers and third-party services have their own policies; review them before connecting.
